# PAN924 VLM Report Dataset Pipeline

This folder builds the canonical VLM instruction dataset for PAN924 panoramic dental radiograph reporting.

The pipeline is fully label-driven:

- FDI numbers come from `annotations/dataset_final_v2.json`.
- Disease/condition labels come from ground-truth annotations.
- Images are split into one full panorama plus four overlapping image-space crops.
- Natural-language `comment` and `summary` fields are generated by deterministic clinical templates.
- No external API is used by the canonical pipeline.

Rare source labels are normalized before training:

```text
Ri, RiM, TeM -> Te
I            -> M3i
```

## Converted Model Formats

`common/*.jsonl` is the only canonical dataset. `converted/` is regenerated from it for each model family:

- `converted/qwen/`: ms-swift/Qwen-VL style JSONL with `messages` plus `images`. The user message keeps the `<image>` placeholder.
- `converted/llava/`: Hugging Face multimodal chat-template style JSONL. Each message `content` is a list of typed image/text items.
- `converted/internvl/`: InternVL single-image JSONL with `image`, `width`, `height`, and ShareGPT-style `conversations`.
- `converted/phi/`: Phi vision prompt/completion JSONL using `<|user|>`, `<|image_1|>`, `<|end|>`, and `<|assistant|>`.
- `converted/paligemma/`: PaliGemma fine-tuning layout with `image`, `prefix`, and `suffix`.

Format references used in `scripts/convert_dataset.py`:

- Qwen/ms-swift custom dataset: https://github.com/modelscope/ms-swift/blob/main/docs/source_en/Customization/Custom-dataset.md
- Hugging Face multimodal chat templates / LLaVA-OneVision: https://huggingface.co/docs/transformers/chat_templating_multimodal
- InternVL chat data format: https://internvl.readthedocs.io/en/latest/get_started/chat_data_format.html
- Phi-3.5 vision input format: https://huggingface.co/microsoft/Phi-3.5-vision-instruct
- PaliGemma processor suffix for fine-tuning: https://huggingface.co/docs/transformers/model_doc/paligemma

## Build Commands

Run from the repository root:

```powershell
..\.venv\Scripts\python.exe .\vlm_report_dataset\scripts\build_5view_common_dataset.py
..\.venv\Scripts\python.exe .\vlm_report_dataset\scripts\generate_clinical_reports.py --input-dir .\vlm_report_dataset\common\raw --output-dir .\vlm_report_dataset\common --splits train val test
..\.venv\Scripts\python.exe .\vlm_report_dataset\scripts\validate_common_dataset.py --input-dir .\vlm_report_dataset\common --report-path .\vlm_report_dataset\common\metadata\validation_report.json
..\.venv\Scripts\python.exe .\vlm_report_dataset\scripts\convert_dataset.py --input-dir .\vlm_report_dataset\common --output-root .\vlm_report_dataset\converted --models qwen llava internvl phi paligemma
```

## Image Splitting

Each source panorama produces five views:

- `full.jpg`
- `image_upper_left.jpg`
- `image_upper_right.jpg`
- `image_lower_left.jpg`
- `image_lower_right.jpg`

The split is annotation-aware:

- `x_split = image_width / 2`
- `upper_y = median center_y` for FDI quadrants 1 and 2
- `lower_y = median center_y` for FDI quadrants 3 and 4
- `y_split = (upper_y + lower_y) / 2`
- fallback: `image_height / 2` if upper/lower annotations are missing
- crop overlap defaults to 10% of width and 10% of height

Region names are image-space names. They describe crop location in the image, not the patient's anatomical left/right.

## Clinical Report Style

The report generator only writes natural-language text fields. It does not change labels.

Comments follow these rules:

- Mention abnormal/non-healthy findings first.
- Group findings by condition.
- Do not list every healthy tooth when abnormal findings exist.
- If all annotated teeth are healthy, use a short healthy-region sentence.
- If no annotated teeth exist, say that no annotated teeth are available.

Example regional target:

```json
{
  "region": "image_lower_right",
  "teeth": [
    {"fdi": "33", "condition": "C", "condition_name": "caries"},
    {"fdi": "34", "condition": "R", "condition_name": "restored"},
    {"fdi": "35", "condition": "H", "condition_name": "healthy"}
  ],
  "comment": "This region shows caries on tooth 33 and a restoration on tooth 34. The remaining annotated teeth are healthy."
}
```

Example full-panorama summary:

```json
{
  "summary": "Overall, the annotated findings include caries on tooth 33, restorations on teeth 16 and 34, and endodontic treatment on tooth 45. The remaining annotated teeth are healthy."
}
```
