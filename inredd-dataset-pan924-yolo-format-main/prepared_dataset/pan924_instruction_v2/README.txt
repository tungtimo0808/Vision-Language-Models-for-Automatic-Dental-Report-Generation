PAN924 Instruction Dataset (Macro + Micro)

Structure:
- macro/macro_labels.csv: Panorama-level labels template
- micro/images/: Contextual square tooth crops
- micro/micro_labels.csv: Tooth-level metadata and labels
- metadata/build_summary.json: Build statistics
- metadata/skipped_items.csv: Items skipped during processing

Notes:
- Columns detailed_report and general_report are left blank for expert annotation.
- *_seed columns provide optional draft hints only.
